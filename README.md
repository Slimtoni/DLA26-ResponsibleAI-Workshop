# DLA 2026 — Participant Materials

Materials for the **Responsible AI Day** workshop session: *Design a Responsible AI Decision-Support System* (Sessions 2–3).

Download this repository at the start of the day — everything you need is here.

## Contents

| Path | What it is |
|---|---|
| [`Task.md`](Task.md) | The task, how the day works, working principles, poster structure, and all guiding questions |
| [`Role-Cards.md`](Role-Cards.md) | Four team roles — one per team member (decision-maker / affected person / regulator / skeptic) |
| `cases/` | Your scenario — case brief + AI system card (one per case, **assigned on the day**) |
| `stakeholder-cards/0X-<case>-stakeholders.md` | Stakeholder cards for that case |

## How to use it

1. Read [`Task.md`](Task.md) during the task intro.
2. Open the case folder for **your assigned case** (announced at 11:00).
3. Each team member picks a role from [`Role-Cards.md`](Role-Cards.md).
4. Structure your A2 poster around the zones in `Task.md`.

> All case data (accuracies, volumes, costs) is **fictional** and invented for this exercise. Regulatory references are starting points, not legal advice — verify before any real deployment.
